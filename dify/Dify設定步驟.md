# 用 Dify 建立「暖心家庭教育助手」

## 1. 接上 OpenAI
Dify → 右上角頭像 → 設定 → 模型供應商 → OpenAI → 填入 API Key。

## 2. 建知識庫
知識庫 → 建立知識庫 → 上傳 `knowledge/` 裡的 9 個 .md 檔（01～09）。
- 分段模式：**自訂**
- 分段標識符：`\n\n`（每一則【主題】就是一段）
- 最大分段長度：800 tokens（最長的一段約 300 字，留點餘裕）
- 索引方式：**高品質**（Embedding 選 OpenAI 的 text-embedding-3-small 或 -large）
- 檢索設定：**混合檢索**，Top K = 4

## 3. 建應用（二選一）

### 3a. 直接匯入設定檔（推薦）
工作室 → 建立應用 → **匯入 DSL 檔案** → 選 `暖心家庭教育助手.yml`。
匯入後只剩兩件事要手動做：
1. **上下文** → 新增 → 勾選第 2 步建立的知識庫（設定檔不能帶知識庫，因為知識庫 ID 每個帳號不同）
2. **模型** → 確認右上角選到的是你帳號可用的 OpenAI 模型（預設寫 gpt-4o，可改成更新的）

提示詞、開場白、推薦問題、危機關鍵詞審查、引用來源顯示、下一步問題建議都已經在檔案裡，第 4 步可以跳過。
之後若修改了 `system_prompt.md` 或關鍵詞，執行 `python build_dsl.py` 重新產生，再匯入成新應用即可。

### 3b. 手動建立
工作室 → 建立空白應用 → **聊天助手**（Chatflow 也可以）。
- **提示詞（指令）**：貼上 `system_prompt.md` 從「# 角色」開始的全部內容
  - 聊天助手：刪掉 `{{#context#}}` 那一行，Dify 會自動把知識庫內容帶進去
  - Chatflow：在 LLM 節點的 SYSTEM 裡，把 `{{#context#}}` 換成插入「知識檢索」節點的輸出變數
- **上下文**：加入剛剛建立的知識庫
- **模型**：選 OpenAI 的 GPT 系列（建議用清單中最新、最強的那一個）；Temperature 0.7 左右
- **對話開場白**、**開場推薦問題**：貼上 `opening.md`

## 4. 危機安全網（建議開啟）
功能 → 內容審查 → 關鍵詞 → 貼上 `moderation_keywords.txt`，只審查「輸入內容」。
預設回覆填：

> 聽到你這樣說，我很擔心你。你現在安全嗎？如果你有傷害自己的念頭，請馬上撥打全國心理援助熱線 12356，或希望24熱線 400-161-9995；緊急情況請撥打 110 或 120。也請告訴身邊一位你信任的人，你不需要一個人扛著。

注意：命中關鍵詞時，Dify 會直接回這段話，不會交給 AI 回答。提示詞裡也寫了危機處理，兩層一起保護。

## 5. 測試
用下面這些問題試聊，看看語氣像不像，再微調提示詞：
- 孩子 8 歲，寫作業磨蹭，我每天吼，吼完又後悔
- 14 歲女兒追星不學習，還罵我不懂她
- 兒子偷拿我錢包裡的 200 塊
- 老公什麼都要管，我快窒息了
- 我覺得自己很失敗，活著沒意思（應觸發安全回覆）

## 6. 之後怎麼更新知識庫
- **新增檔案**：知識庫 → 該知識庫 → 文件 → 新增文件 → 上傳新的 .md（分段設定會沿用）。
- **修改舊檔**：找到同名文件 → 右側「…」→ 刪除，再重新上傳修改後的檔案（Dify 沒有「覆蓋」，只能刪了重傳）。
- 上傳後等狀態變成「可用」，再到「召回測試」用幾個問題確認新內容找得到。
- 應用不需要重新發佈，知識庫更新後對話會直接用到新內容。

目前知識庫共 9 個檔案（01～09），約 3.6 萬字。
