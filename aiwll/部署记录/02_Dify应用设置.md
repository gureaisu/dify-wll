# Dify 应用设置

## 1. OpenAI
- 设置 → 模型供应商：安装插件 `langgenius/openai` 1.0.5，填入 OpenAI API Key
- OpenAI 账户必须先储值：没有额度时会报 `insufficient_quota`（`credit_balance_exhausted`）
- 插件 1.0.5 的模型列表**没有 gpt-4o**，所以改用 **gpt-4.1**（非推理模型、速度快、支持 temperature）
- Embedding：`text-embedding-3-small`

## 2. 知识库「暖心家庭教育知识库」
- 源文件：`aiwll/知识库/` 的 9 个 .md（01～09），共约 3.6 万字，切成 86 段
- 分段：自定义，分段标识符 `\n\n`，最大 800 tokens，重叠 50
- 索引：高质量；检索：混合检索（语义 0.7 / 关键词 0.3），Top K = 4，不开 rerank
- 知识库 ID：`668aaa3c-9f87-4ed8-ba2a-2d5e57cc24ae`
- 更新方式：Dify 不能覆盖文件，要先删除同名文件再上传

## 3. 应用「暖心家庭教育助手」
- 导入 `dify/暖心家庭教育助手.yml`（DSL 0.7.0，由 `dify/build_dsl.py` 生成）
- 导入后在「上下文」加入知识库（DSL 不能带知识库 ID）
- 应用 ID：`55234db6-684d-4a70-bd52-ba3e6b137d41`
- 模型 gpt-4.1，temperature 0.7，max_tokens 1024
- 提示词要求一律用简体中文回答
- 开启：引用来源、回答后推荐问题、内容审查
- Web 应用已开启：http://localhost/chat/oQXVkvXasSShqfLA
- 另外创建了 App API Key，给对外网页用（见 [[03_对外网页部署]]）

## 4. 危机安全网（内容审查）
- 关键词：`dify/moderation_keywords.txt`，27 个（简体 + 繁体，都能命中）
- 只审查输入；命中时直接回复预设内容，不交给 AI
- 预设回复：全国心理援助热线 12356、希望24热线 400-161-9995、紧急情况 110/120
- **Dify 限制预设回复不能超过 100 字**：原本 117 字，导入 DSL 时没被检查，但在界面上保存会失败；已缩短为 98 字，`build_dsl.py` 也加了长度检查
