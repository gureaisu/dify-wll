# 移除与停用

依需求从轻到重选择。

## 1. 暂停对外网页（保留一切）
在 `C:\WorkDir\AIWLL\web`：

    docker compose down

之后要恢复：`docker compose up -d`

## 2. 完全移除对外网页
1. 停止并删除容器：`docker compose down`（在 `web/`）
2. 删除防火墙规则（系统管理员 PowerShell）：

       Remove-NetFirewallRule -DisplayName "AIWLL web 8080"

3. 在路由器删除 8080 的 port forwarding
4. 在 Dify 删除 App API Key：暖心家庭教育助手 → 访问 API → API 密钥 → 删除
5. 删除 `web/.env`

## 3. 停止 Dify（保留数据）
在 `C:\WorkDir\dify\docker`：

    docker compose down

## 4. 完全移除 Dify（会删除所有数据，无法复原）
1. 先确认对外网页已移除（上一节），它依赖 Dify 的 `docker_default` 网络
2. 在 `C:\WorkDir\dify\docker`：

       docker compose down -v

3. 删除数据目录 `C:\WorkDir\dify\docker\volumes\`，再删除整个 `C:\WorkDir\dify`
4. 视需要删除镜像：`docker image prune -a`（会删除所有没在用的镜像，包含其他项目的）

## 5. 清理密钥与账号
- OpenAI：到 https://platform.openai.com/api-keys 删除这次用的 Key（它曾出现在对话记录里，建议无论如何都换一组）
- Dify 管理员密码目前很弱，继续使用的话请先修改

## 6. 其他残留
- 转换简繁时拉取的镜像 `python:3.12-slim`：`docker rmi python:3.12-slim`
- Obsidian 笔记库 `aiwll/` 和 repo 本身不受影响
